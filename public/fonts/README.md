Noto Sans Sinhala 3.000 Regular and Bold are bundled for Sinhala PDF export.

Source: https://notofonts.github.io/sinhala/fonts/NotoSansSinhala/hinted/ttf/

Use this current release, not the 2.002 fonts in the archived noto-fonts repository.
Older releases have overlapping Sinhala glyphs with modern shaping engines:
https://github.com/notofonts/sinhala/issues/1

Filenames include the version so browsers cannot reuse the old cached font.

Copyright and redistribution terms are in OFL.txt (SIL Open Font License 1.1).
The fonts are loaded from this app's own origin, so exports do not depend on a
third-party font service or fonts installed on the user's device.
